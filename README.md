# Sweety – Blood Glucose Tracker

## Project Overview

Sweety is a full-stack web application designed
to help diabetes patients record and monitor
their daily blood glucose readings.

Users can manage their glucose readings and
view daily, month-to-date and monthly reports.

## Technology Stack

### Frontend
- React.js
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- PostgreSQL

### Authentication
- JWT
- bcrypt

### Testing
- Jest
- Supertest
- React Testing Library

## Core Features

1. User registration and login.
2. Secure password hashing.
3. Add, view, edit and delete glucose readings.
4. Reading validation.
5. Daily glucose reports.
6. Month-to-date reports.
7. Previous monthly reports.
